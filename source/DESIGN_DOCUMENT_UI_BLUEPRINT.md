# DESIGN DOCUMENT & UI BLUEPRINT
**Project Name:** Kaushal Setu  
**Design System:** Modern Editorial & High-Contrast Industrial Dashboard  

---

## 1. Visual Identity & Design Tokens

### 1.1 Color Palette
* **Body Background:** Light Off-White (`#F9F8F3`) for content cards and body sections.
* **Dark Contrast Accent:** Charcoal / Dark Navy (`#121212`) for hero banners, top navigation, and secondary UI containers.
* **Primary Brand CTA:** High-Visibility Yellow (`#E2EE58` / `#F3E651`) for primary actions (`Stakeholder Access →`, `Explore the Platform →`).
* **Status Indicators:**
  * **Capacity / Added Skills:** Mint Green (`#10B981` / `#2D6A4F`).
  * **Deficit / Obsolete Modules:** Crimson Red (`#DC2626`).

### 1.2 Typography
* **Primary Serif (Headings):** *Playfair Display* / *Source Serif Pro* for hero headers (`Building skills that connect education with industry.`).
* **Primary Sans-Serif (Body & Controls):** *Inter* / *Plus Jakarta Sans* for dashboard cards, data tables, and metrics.

---

## 2. Layout Structure & UI Modules

### 2.1 Top Navigation Bar
* **Brand Header:** Bold serif logo **Kaushal Setu** with a teal dot indicator.
* **Role Switcher Demo Banner:** Top toggle bar allowing instant perspective switching (`[Public Visitor]`, `[DSDC Govt]`, `[Employer]`, `[ITI Principal]`, `[Trainee]`).
* **Action CTAs:** `Sign In` button alongside yellow `Stakeholder Access →` button.

### 2.2 Hero Section & Public Overview
* Dark hero container displaying serif header, descriptive body text, primary yellow CTA, and outlined secondary CTA.
* Live metric counter strip displaying:
  * `42+ Accredited ITIs`
  * `312 MIDC Manufacturers`
  * `48,200 Annual Vacancies`
  * `78% Placement Target`

### 2.3 Live District Intelligence Card
* Focal region metric header (e.g., *Pune Industrial Cluster - MIDC Chakan-Bhosari*).
* Progress indicator tracking capacity (`34,500 Certified Trainees` vs. `48,200 Industrial Openings` = `71% Capacity`).
* Specific skill deficit highlight box (`5-Axis CNC & CAM Machinists: -1,940 Deficit`).

### 2.4 Architecture Capabilities Accordion
* Accordion list with numerical badges (`01 District Skill Intelligence`, `02 Curriculum Gap Analysis`, `03 Syllabus Diff Engine`, `04 DSAP Exporter`) featuring monospace metric previews.
* Value proposition cards comparing split concepts (*Industry-Aligned Learning* vs. *Human-Guided Decisions*).
